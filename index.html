Les positions, côte à côte

À gauche, la position de départ. À droite, la position à reproduire, nommée comme sur un ukulélé standard.

● Case appuyée · ○ Corde à vide · × Corde muette

Les noms saisis désignent les positions apprises sur le standard, quel que soit l’instrument de départ. Les schémas montrent les cordes de gauche à droite (standard : G–C–E–A ; baryton : D–G–B–E). Le nom « Position F » signifie : reproduisez le doigté de F appris sur le standard. Les formes montrées sont des doigtés possibles, parfois différents des formes habituelles. Un accordage standard avec sol aigu ou sol grave modifie les octaves, pas les noms des accords. Pour les accords avec basse indiquée (ex. C/E), les noms sont convertis mais aucun diagramme d'inversion n'est garanti.
